# Gandhi Rajan - Modern Web Developer Portfolio

A responsive, high-performance web developer portfolio featuring interactive particle effects, a magnetic custom cursor, card spotlights, and cascading scroll reveals.

## Features
- **Interactive Canvas Particles**: Mouse-responsive node/particle network in the hero section.
- **Magnetic Custom Cursor**: Custom cursor dot and trailing circle utilizing linear interpolation.
- **Glassmorphism Spotlight**: Spotlight hover effect on glass elements.
- **Cascading Scroll Reveal**: Intersection Observer-based staggered content entry animations.
- **Contact Form**: Form validation and animated state changes.

## Tech Stack
- **HTML5** (Semantic structure)
- **CSS3** (Vanilla variables, custom transitions, animations)
- **JavaScript** (ES6+, Canvas API, Intersection Observer API)
- **Icons**: Font Awesome 6
- **Fonts**: Outfit & Inter (Google Fonts)

## Setup & Running Locally
To run the project locally, start a simple HTTP server in the project directory:
```bash
# Using Python
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.
